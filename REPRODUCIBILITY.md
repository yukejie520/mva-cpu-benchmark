# Reproducibility package

This package contains scripts and machine-readable outputs for the MVA CPU
benchmark. It does not redistribute COCO images or third-party model weights.

## Environment

Create the environment on the data drive (the local working copy used for the
reported run is `D:\Article\ccf-c-detector-efficiency\.venv`):

```text
python -m venv D:\Article\ccf-c-detector-efficiency\.venv
D:\Article\ccf-c-detector-efficiency\.venv\Scripts\activate
python -m pip install -r requirements-repro.txt
```

Use ONNX Runtime 1.28.0 for the reported INT8 results. Record the operating
system, CPU model, thread count, and package versions in the generated metadata.

## Main benchmark

```text
python scripts/measure_interleaved_7.py --rounds 5 --warmup 20 --reps 30 --n-imgs 8 --threads 16
python scripts/thread_sensitivity_anchors.py --rounds 3 --warmup 20 --reps 30 --n-imgs 8
```

The scripts refuse to silently skip missing ONNX models and write raw CSV,
summary CSV, and JSON metadata under `results/`. The completed local run has
35 model-round records (7 models × 5 rounds) and a rotated model order; the
temperature fields are unavailable on the Windows interface and remain empty.

## Full COCO accuracy

```text
python scripts/prepare_full_coco_val.py
python scripts/evaluate_full_coco_official.py
# If the machine sleeps or the run is interrupted, resume completed JSONs:
python scripts/evaluate_full_coco_official.py --reuse-predictions
python scripts/merge_full_coco_official.py
```

The first command downloads the official `val2017.zip`, verifies its digest if
`--expected-sha256` is supplied, checks for exactly 5,000 images, and writes a
manifest containing image and annotation SHA-256 hashes. Images and weights stay
outside version control. For the submission-grade accuracy table, run
`scripts/evaluate_full_coco_official.py`; it saves per-model COCO detection JSON
files and uses `pycocotools==2.0.11` COCOeval. The
`scripts/evaluate_full_coco.py` NumPy path remains a development-stage audit
tool and must not be labelled official COCO mAP.

The complete-val selective INT8 confirmation uses the same official evaluator
with explicit artifact paths (the artifacts themselves are not redistributed):

```text
python scripts/evaluate_full_coco_official.py --models YOLOv8n_sel,YOLOv8s_sel,YOLOv8m_sel,YOLOv8l_sel --model-spec YOLOv8n_sel=data/yolov8n_static_sel.onnx --model-spec YOLOv8s_sel=data/yolov8s_static_sel.onnx --model-spec YOLOv8m_sel=data/yolov8m_static_sel.onnx --model-spec YOLOv8l_sel=data/yolov8l_static_sel.onnx --pred-dir results/full_coco_int8_predictions --out results/full_coco_int8_selective_official.csv --resume-predictions
```

## INT8 controls and figures

Use `scripts/quantize_int8.py` with explicit `--format` and `--activation`
arguments. Re-run the executed-graph census before updating any INT8 claim.
Figures are generated by `scripts/plot_papers.py`; the manuscript exporter is
`scripts/export_docx.py`.
