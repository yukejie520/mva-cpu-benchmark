# Curated benchmark release data

This directory contains the small, publication-facing data package for the
five-round CPU benchmark. It intentionally excludes COCO images, model
weights, temporary logs, and exploratory files.

- `main7_interleaved_raw.csv`: 35 row-level measurements (7 models × 5 rounds).
- `main7_interleaved_summary.csv`: median, range, p95, and p99 latency summary.
- `main7_metadata.json`: protocol, rotated order, timestamps, and relative model names.
- `thread_sensitivity.csv`: 36 measurements for YOLOv8n, YOLOv8l, and RT-DETR-l at 1/4/8/16 threads over three rounds.
- `model_hashes.csv`: SHA-256 hashes of the seven local ONNX model files used for the benchmark.
- `int8_selective_model_hashes.csv`: SHA-256 hashes of the four selective INT8 artifacts used for the complete-val confirmation.
- `full_coco_map.csv`: unified 5,000-image COCO val2017 FP32 evaluation for all seven models.
- `full_coco_int8_selective.csv`: unified 5,000-image COCO val2017 confirmation for the four detection-head-preserving YOLO INT8 artifacts, with FP32 deltas.
- `full_coco_manifest.json`: image/annotation counts and SHA-256 hashes; the images and annotations are not redistributed.
- `full_coco_image_list.txt`: deterministic list of the 5,000 COCO validation image names.
- `environment.txt`: interpreter, operating system, CPU, runtime, and key package versions.

The submission-grade full-val accuracy values are generated by
`scripts/evaluate_full_coco_official.py` with `pycocotools==2.0.11`.
The older `results/full_coco_map_numpy_custom.csv` is an audit artifact and is
not part of the release table.

The annotation provenance check is complete. The local
`annotations_trainval2017.zip` is 252,907,541 bytes with MD5
`f4bbac642086de4f52a3fdda2de5fa2c`, matching the official COCO archive's
published ETag for
[`annotations_trainval2017.zip`](https://images.cocodataset.org/annotations/annotations_trainval2017.zip).
The extracted `annotations/instances_val2017.json` has SHA-256
`e8c7f7908f1d7278341fae127d0da654f102f11bd7b21d8aeefa635b8c810b6f`, the
same hash as the working annotation file. The current annotation is therefore
byte-for-byte identical to the official archive entry; the original mirror
provenance is retained in the audit notes for transparency.
COCO images and third-party model weights are intentionally excluded; download
them separately and verify the hashes in `full_coco_manifest.json`.
